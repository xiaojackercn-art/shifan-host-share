# 视饭AI:主机共享

一个 Windows / macOS 跨电脑键鼠共享工具。两台电脑分别连接自己的显示器，鼠标移动到主控屏幕边缘后进入第二台电脑，键盘自动跟随。

## v0.2.0 重构重点

v0.1 的自研 pynput 键鼠传输协议已停止作为核心。v0.2 使用成熟的开源 **Deskflow 1.26.0** 作为实际键鼠共享引擎，本项目负责：现代桌面 UI、设备配对码、局域网网卡识别、屏幕方向配置、一键启动/停止和安装打包。

### 使用方式

1. 两台电脑都安装并打开“视饭AI:主机共享”。
2. 第二台电脑把界面显示的 **推荐局域网 IP + 本机安全配对码** 告诉主控电脑。
3. 主控电脑填写 IP、配对码，选择第二台屏幕实际在左/右/上/下。
4. 点击 **启动主机共享**。
5. 状态变为“连接成功”后，鼠标推向对应屏幕边缘即可跨屏，键盘跟随鼠标。

无需再分别填写“鼠标密钥 / 键盘密钥”；一个设备配对码同时完成授权，更不容易输错。

## Windows

Release 主下载为 `ShifanAI-HostShare-Setup-x64.exe`，这是正式安装向导，不是把 portable EXE 改名。安装器会创建开始菜单/桌面快捷方式并添加本软件所需的专用网络防火墙规则。

## macOS

Release 分 Apple Silicon 和 Intel 两个 DMG。首次使用 macOS 会要求“辅助功能 / 输入监控”权限，这是系统对键盘鼠标控制软件的强制安全机制。

## 网络

软件会列出本机所有可用私有 IPv4，并优先推荐物理 Wi-Fi / Ethernet 地址。连接第二台电脑时，会按第二台 IP 实际路由重新确认主控 IP，避免 VPN / 虚拟网卡导致 `10.x` 与 `192.168.x` 选错网卡。

默认端口：35999/TCP 为设备配对控制通道；24861/TCP 为 Deskflow 键鼠通道。

当前设计面向同一可信局域网。配对控制指令使用 HMAC-SHA256 证明配对码，配对码本身不会明文发送；Deskflow v0.2 集成默认不启用 TLS，以避免无界面自动配对时额外的证书指纹确认。不要在不可信公共 Wi-Fi 上使用。
