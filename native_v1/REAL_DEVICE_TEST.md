# v1.0.0-alpha.3 两台实体电脑验收规范

> 本文用于真机验收，不用于“编译通过”判定。两台电脑必须安装完全相同的版本。

## 一、首轮环境

推荐优先验证：**Windows 11 主控 → Windows 11 被控**。

准备条件：

- 两台电脑处于同一局域网；
- 退出旧版 v0.9 / Deskflow 以及其它会抢占全局键鼠 Hook 的 KVM 软件；
- 两台电脑安装 `v1.0.0-alpha.3`；
- 主控电脑连接实际键盘和鼠标；
- 被控电脑保持软件运行。

## 二、连接验收

1. 主控电脑选择“主控电脑”。
2. 被控电脑选择“被控电脑”。
3. 主控电脑进入“连接电脑”。
4. 点击“自动查找另一台电脑”。
5. 发现被控电脑后点击“连接这台电脑”。
6. 输入被控电脑显示的 `XXXX-XXXX-XXXX` 配对码。
7. 进入“屏幕位置”，按真实方向放置第二块屏幕并贴边。
8. 开始共享。

通过标准：

- 无需手动输入 IP 即可发现；
- 配对一次成功；
- 屏幕布局保存后立即生效；
- 停止共享后鼠标和键盘立即回归本机。

## 三、鼠标低延迟验收

### A. 慢速连续移动

跨入被控电脑后，以圆形、横向和纵向缓慢移动 30 秒。

要求：

- 轨迹连续；
- 不出现周期性停住后突然追上；
- 不出现明显大段跳帧；
- 光标不自动弹回主控电脑。

### B. 快速甩动

连续快速左右甩动 30 秒，再上下快速移动 30 秒。

要求：

- 被控光标能持续跟手；
- 不出现几百毫秒级“卡住再跳”的现象；
- 快速回到屏幕边缘时能正常跨回主控电脑。

### C. 拖拽

在被控电脑拖动窗口或文件 20 次。

要求：

- 鼠标按住期间移动连续；
- 松开后不会继续保持按下状态；
- 跨回主控电脑后被控端不会残留拖拽状态。

## 四、键盘验收

鼠标停留在被控电脑后，打开记事本或普通文本输入框。

依次测试：

1. `abcdefghijklmnopqrstuvwxyz`
2. `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
3. 数字 `0-9`
4. 空格、Enter、Backspace、Delete
5. 方向键、Home、End、PageUp、PageDown
6. 长按一个字母 5 秒
7. 快速连续输入 100 个字符
8. `Ctrl+A`、`Ctrl+C`、`Ctrl+V`、`Ctrl+Z`
9. `Shift` 组合输入
10. 鼠标持续快速移动的同时连续打字 20 秒

通过标准：

- 键盘焦点跟随鼠标到被控电脑；
- 普通按键全部能输入；
- 快速移动鼠标时键盘仍能正常响应；
- 长按不会中途失效；
- 跨回主控电脑后 Ctrl / Shift / Alt 不会卡住；
- 再次跨入被控电脑后键盘无需重新连接即可继续使用。

## 五、鼠标按键与滚轮

测试：

- 左键单击、双击；
- 右键；
- 中键；
- 垂直滚轮；
- 有侧键的鼠标测试前进/后退。

要求所有输入与被控电脑本地使用一致。

## 六、停止、重连与异常恢复

至少执行 10 次：

1. 开始共享；
2. 跨入被控电脑；
3. 输入文字并移动鼠标；
4. 跨回主控电脑；
5. 停止共享；
6. 再次开始共享。

随后：

- 关闭被控软件再打开；
- 断开网络 10 秒再恢复；
- 主控软件退出后重新打开。

要求：

- 不出现按钮永久停留在“连接中”；
- 不需要重新填写 IP；
- 已配对设备可以恢复；
- 断线后不残留远端按键或鼠标按下状态。

## 七、Windows 权限场景

先在普通记事本通过键盘和鼠标测试，再测试“以管理员身份运行”的程序。

如果只有高权限窗口无法接受键盘/点击，而普通应用正常，需要检查被控端的管理员模式和系统级输入服务，不应把这种情况误判为网络延迟。

## 八、稳定性门槛

### Alpha → Beta

Windows → Windows 连续运行 30 分钟：

- 无明显鼠标周期性卡顿；
- 无键盘失效；
- 无卡键/卡鼠标按钮；
- 无自动断开且无法恢复。

### Beta → Stable

完成 Windows ↔ macOS、剪贴板、多显示器和 12 小时长时间运行测试。

## 九、失败时需要的诊断信息

不要只描述“卡”或“键盘不行”。在两台电脑分别打开：

**设置与排障 → 诊断 → 复制诊断信息**

同时记录：

- 哪台是主控、哪台是被控；
- Windows 版本；
- 有线还是 Wi‑Fi；
- 问题发生时鼠标是否已在被控屏幕；
- 普通记事本能否输入；
- 管理员程序能否输入；
- 问题发生前是否持续高速移动鼠标。

这组信息可以把问题定位到发现、配对、QUIC、输入捕获、键盘路由或 Windows 注入中的具体一层。
