# 版本记录

## v1.0.0-alpha.3

### 输入体验

- Windows 远端指针移动改为直接的绝对光标定位路径，减少高频合成输入开销。
- 鼠标移动发送间隔由 8 ms 调整为 4 ms。
- Windows 键盘 Hook 使用独立远端目标缓存，不再等待鼠标高频状态锁。
- Windows 键盘注入优先使用扫描码，无法映射扫描码的键继续使用虚拟键路径。
- 远端退出、链路失败和主动释放时同步清空键盘目标及按键状态。

### Windows 安装

- NSIS 安装语言固定为简体中文。
- 安装、更新、停止输入服务和防火墙配置等状态提示中文化。
- 修复品牌字符串替换影响 `MyKVMInputService` 内部服务名的问题。

### 界面

- 重做产品视觉覆盖层：统一桌面字体、字号、间距、卡片、按钮、输入框和焦点样式。
- Logo 从裁切显示改为完整适配显示，避免图形被放大裁切。
- 调整默认窗口尺寸和最小窗口尺寸，减少低分辨率下的文字拥挤。
- README、使用说明、架构说明和真机验收标准同步更新。
