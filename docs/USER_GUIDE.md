# 视饭AI：主机共享使用说明

## 一、准备工作

两台电脑需要：

- 安装相同版本的视饭AI：主机共享；
- 接入同一个局域网；
- Windows 防火墙允许本程序的局域网 UDP 通信；
- 被控电脑保持软件运行。

## 二、首次连接

### 主控电脑

选择 **“是，这台是主控电脑”**。这台电脑连接实际使用的键盘和鼠标。

### 被控电脑

选择 **“不是，这台是被控电脑”**。保持软件打开，等待主控电脑连接。

### 配对

在主控电脑：

1. 打开“连接电脑”；
2. 点击“自动查找另一台电脑”；
3. 找到目标设备后点击“连接这台电脑”；
4. 输入被控电脑显示的 `XXXX-XXXX-XXXX` 配对码；
5. 配对成功后进入“屏幕位置”；
6. 将被控屏幕拖到真实方向并贴住主控屏幕边缘。

## 三、日常使用

鼠标推到已配置的屏幕边缘后会进入被控电脑。进入远端后：

- 鼠标移动、点击和滚轮由被控电脑执行；
- 键盘输入自动跟随到被控电脑；
- 跨回主控屏幕后，键鼠控制权自动回到本机。

## 四、Windows 键盘或点击无效

先确认是否只在某个“以管理员身份运行”的程序中失效。

Windows 会限制普通权限进程向更高权限窗口注入键盘和点击。如果普通桌面应用可以正常控制，而管理员程序或 UAC 界面不响应，可在“设置与排障”检查管理员模式和系统级输入服务状态。

如果所有窗口都无法键盘输入：

1. 确认主控电脑鼠标已经真正进入被控屏幕；
2. 在被控电脑普通文本框中测试字母、数字、退格和 Enter；
3. 停止共享后重新开始一次；
4. 仍异常时，在两台电脑分别打开“设置与排障 → 诊断”，复制诊断信息。

## 五、鼠标延迟或卡顿

优先检查：

- 两台电脑是否处于同一稳定局域网；
- Wi‑Fi 是否存在弱信号、漫游或高丢包；
- 是否同时运行其它远程控制/KVM 软件抢占全局键鼠 Hook；
- 显示器位置是否真实贴边，而不是重叠；
- 是否安装的是同一个最新版本。

v1.0.0-alpha.3 已针对 Windows 高频鼠标处理、远端指针注入和键盘抢锁做专项优化。

## 六、解除连接

如需重新配对，可在“设置与排障”中解除当前配对关系，再从“连接电脑”重新发现和配对。
