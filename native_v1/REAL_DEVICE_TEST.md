# Native Alpha 实机验收标准

本文用于验证 **视饭AI:主机共享 Native** 的真实设备体验。CI 编译通过只能证明代码和安装包可以构建，不能代替两台实体电脑的输入体验测试。

## 当前优先级

Windows ↔ Windows 公网连接与鼠标跨屏已经完成第一轮实机验证。当前版本的重点是：

1. 公网鼠标移动的连续性与延迟；
2. Windows 键盘事件完整转发；
3. 点击、滚轮和组合键；
4. 网络抖动后的恢复行为；
5. 新界面、Logo 与中文安装体验。

## 测试环境记录

每次测试请记录：

- 主控电脑系统版本；
- 被控电脑系统版本；
- 两台电脑是否处于不同网络；
- 主控鼠标回报率（如 125 / 500 / 1000Hz，可选）；
- 两侧网络类型（有线 / Wi‑Fi / 手机热点）；
- 软件版本号；
- 是否使用管理员权限运行。

## Windows → Windows 公网测试

### A. 安装与启动

1. 两台电脑卸载或彻底退出旧版本。
2. 两台电脑安装同一个 `ShifanAI-HostShare-Windows-x64-Setup.exe`。
3. 安装向导、安装路径、完成页应为简体中文。
4. 打开软件，确认 Logo、标题、正文在 100%、125%、150% DPI 下清晰。

### B. 建立连接

1. 被控电脑选择 **被控电脑**。
2. 等待状态变为“本机已准备好接收控制”。
3. 复制 `SFAI1-` 连接密钥。
4. 主控电脑选择 **主控电脑**。
5. 粘贴密钥并点击 **建立连接**。
6. 不输入 IP、不配置端口、不修改路由器。
7. 设置真实屏幕方向。

通过标准：连接成功后，主控设备列表显示被控电脑并处于“可控制”状态。

### C. 鼠标低延迟测试

测试动作：

1. 鼠标进入被控电脑后快速左右连续移动 30 秒；
2. 快速画圆 30 秒；
3. 快速往返主控 / 被控屏幕 20 次；
4. 移动过程中短暂断开被控电脑网络 2~3 秒，再恢复；
5. 网络恢复后立刻停止移动鼠标。

通过标准：

- 鼠标轨迹连续，不出现明显“移动一下、停一下”的节拍感；
- 网络短暂抖动后不会继续播放中断期间积压的旧坐标；
- 停止物理鼠标后，远端鼠标应快速停在最新位置，不继续追赶历史轨迹；
- 连续运行 5 分钟后，不出现延迟越来越大的现象。

说明：公网传输存在物理 RTT，验收目标是消除软件自身造成的队列延迟和卡顿，而不是宣称网络传播时间为 0ms。

### D. 键盘测试

鼠标保持在被控电脑上，依次测试：

- `a-z`；
- `0-9`；
- 空格、Enter、Backspace、Tab、Esc；
- 四个方向键；
- Home / End / PageUp / PageDown；
- 左右 Shift；
- Ctrl+C / Ctrl+V；
- Ctrl+A；
- Alt+Tab；
- Win 键；
- 长按一个字母 3 秒；
- 快速连续输入一段中英文文本。

通过标准：

- 普通按键在被控电脑正常输入；
- KeyDown / KeyUp 成对，不出现按键卡住；
- Ctrl / Shift / Alt / Win 不残留为按下状态；
- 从被控电脑切回主控电脑后，所有远端按键自动释放；
- 快速移动鼠标的同时输入文字，键盘事件不能被鼠标数据挤压或丢失。

### E. 鼠标按钮与滚轮

测试：左键、右键、中键、侧键（如有）、垂直滚轮、水平滚轮（如有）、按住左键拖拽。

通过标准：点击与拖拽不丢失，释放鼠标后远端不存在“按键一直按住”的状态。

## Windows 权限场景

Windows 的普通桌面和安全桌面属于不同权限边界。至少分别测试：

- Windows 桌面 / 资源管理器；
- 浏览器；
- 普通记事本；
- 以管理员身份运行的程序；
- UAC / 锁屏（需要输入辅助服务支持时单独记录）。

如果只有管理员程序无法接收键盘，但普通程序正常，应记录为 Windows UIPI / 权限路径问题，而不是公网传输失败。

## Windows ↔ macOS

Windows → Windows 达到上述标准后，再验证：

1. Windows 主控 → macOS 被控；
2. macOS 主控 → Windows 被控。

macOS 首次运行必须授予辅助功能 / 输入监控权限。测试报告应明确区分：网络已连接、捕获权限、注入权限三个状态。

## 稳定性

Beta 前至少完成：

- 30 分钟持续键鼠操作；
- 休眠 / 唤醒一次；
- 网络切换一次；
- 软件退出并重新启动一次；
- 被控电脑断线并恢复一次。

Stable 前建议完成 8~12 小时后台运行测试，并记录 CPU、内存和输入延迟是否随时间增长。
