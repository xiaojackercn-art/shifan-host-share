# 视饭AI:主机共享

一个面向 **Windows + macOS** 的局域网键鼠共享工具。两台电脑分别连接各自的显示器，软件连接成功后，主控电脑的鼠标推到屏幕边缘即可进入第二台电脑，键盘会随鼠标焦点一起切换。

> 当前版本：v0.1.0（首个可测试版本）

## 设计目标

- 两台电脑都只需要打开同一个软件。
- 第二台电脑自动生成并显示 **鼠标密钥** 和 **键盘密钥**。
- 主控电脑输入第二台电脑的 IP、鼠标密钥、键盘密钥，选择第二台屏幕在左/右/上/下，点击“保存并启动共享”。
- 鼠标越过主控电脑对应屏幕边缘后，自动进入第二台电脑。
- 鼠标在第二台电脑移动到返回边缘时，自动回到主控电脑。
- 键盘跟随鼠标焦点，不需要额外快捷键切换。
- 断线自动重连。
- 连接内容使用由两组密钥派生的 Fernet 会话密钥加密，密钥本身不会在网络中明文发送。

## 使用方法

### 第二台电脑

1. 打开软件。
2. 记下软件上方显示的：本机 IP、端口、鼠标密钥、键盘密钥。
3. 保持软件运行。

### 主控电脑

1. 打开软件。
2. 在“主控电脑”区域输入第二台电脑的 IP、端口、鼠标密钥、键盘密钥。
3. 选择第二台显示器现实中的方向，例如第二台屏幕在右边就选“右侧”。
4. 保持“鼠标共享”和“键盘共享”开启。
5. 点击 **保存并启动共享**。
6. 显示“已连接”后，把鼠标一直推向第二台屏幕方向即可跨屏。

两台电脑必须在同一个局域网中。建议先关闭 VPN/代理的局域网隔离功能进行测试。

## Windows 注意事项

首次监听局域网端口时 Windows Defender 可能弹出防火墙提示，请允许 **专用网络**。软件内也提供“修复 Windows 防火墙”按钮，会请求管理员权限，仅为本软件 TCP 端口添加入站放行规则。

## macOS 注意事项

macOS 对键盘鼠标监听和模拟输入有系统级权限保护。首次运行后请前往：

**系统设置 → 隐私与安全性 → 辅助功能 / 输入监控**

允许“视饭AI主机共享”。未签名/未公证的测试构建第一次打开时，可能需要在 Finder 中右键应用并选择“打开”。正式对外分发建议使用 Apple Developer ID 签名与 notarization。

## 技术结构

- Python 3.12
- Tkinter：桌面 UI 和主控端透明输入接管层
- pynput：Windows/macOS 原生键盘鼠标监听与输入模拟
- TCP：低延迟局域网事件传输
- cryptography/Fernet：连接数据加密
- PyInstaller：生成 Windows EXE 和 macOS APP
- GitHub Actions：分别在 Windows x64、macOS Intel、macOS Apple Silicon Runner 上原生构建

## 当前适用范围

v0.1.0 优先针对“一台电脑一个屏幕、两台电脑同一局域网”的实际场景落地。多显示器拓扑、跨公网中继、剪贴板/文件共享计划放到后续版本。

## 安全边界

软件只监听本机局域网 TCP 端口，不提供公网中继、静默安装、隐藏运行或绕过系统授权功能。连接端必须持有第二台电脑界面上显示的两组密钥。
